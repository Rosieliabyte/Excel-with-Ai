# Excel-with-Ai
# Microsoft Excel Projects & Practice

## About This Repository

This repository showcases my hands-on practice and assignments in **Microsoft Excel**, focusing on data cleaning, data analysis, reporting, financial statements, and interactive dashboards.

Through these exercises, I have developed practical skills in organizing raw data, applying Excel formulas, summarizing information, and presenting insights through tables, charts, and dashboards.

## Skills & Concepts Covered

### 1. Data Cleaning & Organization

* Cleaning and organizing raw datasets
* Converting data into structured Excel tables
* Using filters and sorting to organize information
* Preparing datasets for analysis and reporting

### 2. Excel Formulas & Functions

* **VLOOKUP & XLOOKUP** — Retrieving data from tables
* **CHOOSE & MATCH** — Working with lookup values and positions
* **SUMIFS** — Calculating totals based on multiple criteria
* **COUNTIF** — Counting records that meet specific conditions
* Practicing logical formulas and other essential Excel functions

### 3. Data Analysis & Summarization

* Creating PivotTables to summarize large datasets
* Filtering and sorting data for meaningful analysis
* Using formulas to calculate totals and analyze records
* Organizing information into clear, structured reports

### 4. Dashboards & Data Visualization

* Creating Excel dashboards to present key information
* Building charts to visualize data and trends
* Using PivotCharts and summarized data for reporting
* Improving the presentation of analytical results

### 5. Financial Statements

Preparing and working with financial statements in Excel:

* **Profit & Loss Statement (P&L):** Summarizing revenue, expenses, and profit or loss
* **Balance Sheet:** Organizing assets, liabilities, and equity
* **Cash Flow Statement:** Presenting cash inflows and outflows

These exercises help me understand how Excel supports financial reporting and accounting-related analysis.
